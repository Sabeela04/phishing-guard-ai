# Phishing Guard AI Frontend

A standalone frontend prototype for the Phishing Guard AI project.

## Run
Simply double-click `index.html` and open it in a browser.

No installation is required.

## Current prototype
- Dashboard UI
- URL Scanner
- Email Scanner
- Risk score visualization
- Explainable detection signals
- Allow / Warn / Quarantine response
- Recent scan history
- Responsive layout

## Next step
Connect the JavaScript functions `analyzeURL()` and `analyzeEmail()` to a Python/FastAPI or Node.js backend. The current client-side rules are only for demonstrating the workflow.
